# hoshi-no-yashiro（星の社）

3D創世瞑想アプリ。触ると光の塵が集まって星が生まれ、生まれた神様が宇宙を漂う。
クロちゃんデザインの2D版「八百万の神々」を3D化する構想の Phase 1。

## 遊び方

* `index.html` をブラウザで開くだけ（ビルド不要。Three.jsはCDNから読む＝ネット接続が必要）
* お参り: 呼吸モードを選び、光のリングに合わせて3呼吸 → 画面に8秒触れて星を迎えると神様が誕生
* 奉納の舞: 縁を結んだ神様が円座に並び、太鼓に合わせて光の環が近づく。環が重なる刹那にタッチすると祝詞が届く
* 右上の🔇でヒーリング音のON/OFF（音はコード生成、音声ファイルなし）
* スマホのタッチでも同じ操作

### 龍神様の素材について
`video/ryujin.mp4` と `img/ryujin.webp` は、いいともさんが Google Gemini で生成したもの。
右下にあった可視ウォーターマーク（✦）は、下端をクロップして除いてある（動画は下146px・画像は下148px）。
**AI生成であることは guide.html に明記すること**（語りのVOICEVOXクレジットと並べてある）。
なお SynthID（目に見えない電子透かし）は残っているので、生成元の記録自体は消えていない。

* 龍神様の顕現 公開（2026-08-10・クロちゃん/Opus 5）
  * **前がひどかった**: 半径13の輪をぐるぐる回るだけ（距離が一切変わらない）＋ 誕生の5秒後に全画面オーバーレイ。実質2秒しか見えていなかった
  * 映像（Gemini生成）を全画面で10秒流し、終わりの光の炸裂から画面の光へ引き継ぎ、消えたあとは粒子の龍が空間に残って泳ぎつづける
  * 粒子の龍も作り直し: 160粒→**520粒**、角・髭・鬣・目を追加。`dragonPathAt(tau)` が軌跡を返し、胴は頭より遅れた tau を辿る（＝自然にうねる）
  * 軌道は霧の奥 `z=-110` から、`DRAGON.pass` の瞬間にちょうどカメラ `z=32` を通過し、旋回して遊泳へ。遊泳は遅いので胴の時間差を `lagSteady` 倍に伸ばす（伸ばさないと塊に見える）
  * 待ち時間: 映像ありは17.5秒／なしは15秒（前は5秒）
  * 映像は `preload="none"`。`ryujinRemain() <= 3` になって初めて読み込む。間に合わなければ黙って粒子だけで成立する
  * 音は映像の音声。映像が出せないときだけ `playDragonRoar()`（55Hzの唸り＋すれ違いの高音）
  * sw.js は `.mp4` を横取りしない（Range取得が壊れるため）
  * ローカル確認用に `?ryujin`（localhost限定。本番では動かない）と `_hoshi.snap(幅, 秒)`
  * **注意**: ブラウザのタブ／プレビューペインが非表示だと rAF も動画再生も止まる。演出の確認は必ず表に出した画面で

* おみくじの偏りを直した（2026-08-10・クロちゃん/Opus 5）
  * **同じ時間に来る人へ同じ神ばかり出ていた**。時間帯とモードの重みが `+2`（基礎1に対して5倍）と強すぎたため。占いはその日その日の運勢であってほしいので `+0.6` へ
  * **まだ会っていない八柱を 2.5倍** 出やすく。八柱そろうまでが長すぎた（中央値33日・遅い人60日・最長166日）
  * → 中央値 **15日**・遅い人23日・最長59日に短縮
  * 節気の二十四柱に「ふさわしい刻」を持たせた（`hours` と `when`）。冬至は「いちばん長い夜」、白露は「夜明けの草の上」、春分は「明け方と夕暮れ」など、節気の意味そのまま
  * **出ない時間は作らない**（下支え `+0.2`、ふさわしい刻は `+1.4`）。ふさわしい刻21.4%／ほかの刻10.9%＝ほぼ2倍差
  * 御朱印帳の節気の章に、いまの神とその刻をヒント表示。知らせなければ時刻を選ぶ意味がないため
